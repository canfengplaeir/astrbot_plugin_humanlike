# 拟人化群聊助手 (astrbot_plugin_humanlike)

让 AstrBot 在群聊中像真人一样说话——不再每条消息都回复，而是基于心流引擎、消息累积和 AI 判断，自主决定何时参与对话。

## 核心问题

默认 AstrBot 对群聊**每条消息**都回复，像话痨。本插件解决三个问题：

| 问题 | 方案 |
|------|------|
| 每条消息都回复 | 心流引擎 + 累积模式 → 有选择地参与 |
| 短时间刷屏 | 防抖 → 动态冷却 + 频率限制 + 随机沉默 |
| 回复缺乏人格 | 继承 AstrBot 人格系统 → 猫娘/傲娇等人设完整保留 |

## v1.1 更新内容

- ⏱️ **AI 调用超时**：判断/回复/关键词/主动发言均可独立配置超时，模型卡住不再挂起回复流程

**Bug 修复：**
- 修复批处理并发触发导致的**重复回复**与处理期间新消息**被清空丢失**的问题
- 修复"活跃度加成"统计了机器人自己的回复而非群消息、几乎永远不会触发的问题
- 修复 Dashboard 保存设置时把未展示的配置（如 `judge_provider_id`）覆盖清空的问题

- 修复 sys.modules 全局清理可能影响其他插件的问题（改为相对导入）
- 人格读取加入 TTL 缓存，高活跃群聊下大幅减少重复读取

## 四大子系统

### 1. 心流引擎 (Flow Engine)

模拟人类注意力波动，每个群独立维护 0-100 的心流值。

**上升机制：**

| 触发条件 | 加成 | 说明 |
|----------|------|------|
| 被 @提及 | +45 | 直接叫到机器人 |
| 名字被提到 | +45 | 人格名或 bot_name 出现在消息中 |
| 匹配关键词 | +15 | 配置的兴趣话题 |
| 消息含问号 | +25 | 可能有人在提问 |
| 群聊活跃 | +3 | 60秒内多人发言 |
| 回复互动 | +15 | 机器人发言后 30s 内被叫名字 |

**下降机制：**

| 触发条件 | 衰减量 |
|----------|--------|
| 自然流失 | 每秒 -0.15 |
| 发言后衰减 | -12 |
| 同一人连续发言 | -3/条（第 3 条起） |

### 2. 消息累积 (Accumulation)

模拟人看手机的习惯——消息轰炸时先不回复，安静下来再一起看。计时器带 ±30% 随机抖动，避免机械感。

**两条路径：**

| 路径 | 触发条件 | 行为 |
|------|----------|------|
| 立即处理 | 被@、被叫名字、心流≥55 | 跳过等待，直接判断回复 |
| 累积等待 | 普通聊天消息 | 加入缓冲队列，3±1s 无新消息后批量处理 |

### 3. 消息防抖 (Debounce)

三层保护避免刷屏：

- **动态冷却**：心流 100→8s，心流 50→30s，心流 0→60s
- **频率限制**：默认每 5 分钟最多 12 次
- **随机沉默**：默认 2% 概率
- **防抖重试**：拦截后 20s 退避重试，超 3 次跳过防抖直接交 AI 判断

### 4. AI 判断与回复

两级 LLM 调用。人格继承自 AstrBot WebUI 配置，插件不覆盖。支持为判断和回复分别配置不同模型（降低成本）。所有 LLM 调用均带超时（可在 Dashboard 配置），超时/失败自动回退启发式规则，不会挂起流程。

### 5. 主动发言 (Proactive)

群聊冷场后，机器人像真人一样主动开口（默认关闭）：

| 配置 | 默认 | 说明 |
|------|------|------|
| 启用主动发言 | 关 | 开启后周期性检查各群 |
| 静默阈值 | 30 分钟 | 群聊连续无消息多久后考虑发言 |
| 主动冷却 | 60 分钟 | 两次主动发言最小间隔 |
| 最低心流 | 40 | 心流不足时不打扰 |
| 每日上限 | 3 次/群 | 防止话痨 |

触发后由 LLM 结合人格与最近聊天内容决定：要么保持沉默，要么输出 1-2 句起话题的话。主动发言同样计入防抖窗口与心流衰减。

## WebUI 页面

插件提供统一的 **Dashboard** 页面，左侧边栏切换三个功能面板：

| 面板 | 功能 |
|------|------|
| **插件设置** | 全部配置项可视化操作：开关/滑块/数字输入/下拉/提示词编辑/AI判断专用模型选择，一键保存即时生效 |
| **关键词管理** | 手动添加删除 + AI 生成（可选人格，兼容 v2/v3 人格系统）+ 实时关键词测试器 |
| **状态面板** | 所有群心流进度条、发言统计、最近消息、缓冲数、主动发言状态，10s 自动刷新 |

## 指令

| 指令 | 说明 |
|------|------|
| `/mindflow` | 查看当前群状态：心流值、上次发言、缓冲 |
| `/mindflowreset` | 重置当前群状态 |
| `/keywords` | 查看已生效的关键词 |
| `/genkeywords` | AI 根据人格生成关键词 |

## 设计原则

1. **人格不覆盖**：继承 AstrBot PersonaManager，用户人设完整保留
2. **累积优先**：消息爆发时缓冲，安静后批量处理，模拟人类读消息行为
3. **防抖优先于 AI**：防抖检查在 LLM 调用之前，避免不必要的 API 开销
4. **错误容忍**：AI 调用失败自动回退启发式规则
5. **群间隔离**：心流、上下文、计时器、缓冲全部按群独立
6. **拟人细节**：计时器随机抖动、同人打断惩罚、回复互动奖励
