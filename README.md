# 拟人化群聊助手（astrbot_plugin_humanlike）

一个 AstrBot 插件：让机器人在群聊中按心流和 AI 判断决定是否发言，而不是每条消息都回复。

插件不管理人格。机器人的性格、名字、语气全部来自 AstrBot 当前选中的默认人格，插件只决定三件事：何时说、说多少、要不要主动说。

## 功能

### 心流引擎

每个群独立维护一个 0-100 的"参与意愿"值，随时间自然衰减，被刺激时上升。以下为「日常闲聊群」预设的默认值，全部可调。

上升：

| 触发条件 | 加成 | 说明 |
|---|---|---|
| 被 @ | +35 | 直接叫到机器人 |
| 人格名被提到 | +35 | 名字出现在消息里 |
| 话题偏好 | 仅作 AI 上下文提示 | 默认不直接改变心流；可在设置中开启本地话题加成 |
| 消息含问号 | +20 | 可能有人在提问 |
| 群聊活跃 | +10 | 60 秒内多条消息 |
| 回复互动 | +15 | 机器人发言后 30 秒内被叫名字 |

下降：

| 触发条件 | 衰减量 |
|---|---|
| 自然流失 | 每秒 -0.03 |
| 发言后 | -18 |
| 同一人连续发言 | 第 3 条起每条 -3 |

### 消息累积

消息多的时候先不回复，等群里安静下来再一起看，模拟人看手机的习惯。计时器带 ±30% 随机抖动。

- 立即处理：被 @、被叫人格名、心流 ≥ 70，跳过等待直接判断
- 累积等待：普通消息进缓冲，安静 15±30% 秒后批量处理；缓冲满 15 条强制处理

### 防抖

- 动态冷却：心流高时冷却短（4 秒），低时冷却长（10 秒）
- 频率限制：默认每 60 秒最多回复 12 次
- 随机沉默：默认 10% 概率保持沉默
- 被点名（@）时豁免全部防抖检查，必定回复
- 多条 @ 同时到达时按顺序排队，前一条回复生成完成后继续处理，避免并发生成重复回复或把点名消息误放入普通20秒累积等待。

### AI 判断与回复

两级 LLM 调用：先判断是否发言，通过后再生成回复。判断和回复可以配置不同的模型。所有 LLM 调用都有超时（判断 12 秒 / 回复 45 秒 / 话题 30 秒 / 主动 25 秒），超时或失败按沉默处理，不会卡住流程。话题偏好默认只作为判断上下文，不会单独触发回复。

@ 归属处理：提示词会明确标注消息的 @ 对象——「@了你」「@了其他成员」「@全体成员」；判断提示词固定附加"消息归属"原则。被点名时跳过 AI 判断直接回复，@ 别人的消息正常走判断流程，AI 不会误以为在叫自己。

图片理解：插件会从 AstrBot 消息链读取图片 URL 或本地缓存路径，并通过 AstrBot provider 的多模态接口传给当前聊天模型。图片消息、纯图片消息和 GIF 表情包都会进入 AI 判断与回复；消息累积时也会保留附件。判断时图片只提供语境，单独发送的表情包或 GIF 默认倾向沉默；图片中的明确问题或与当前讨论直接相关时仍可参与。当前聊天模型必须支持视觉输入，例如 DeepSeek 的 `deepseek-flash`。若设置了单独的判断模型，含图片时会改用当前聊天模型判断，避免文本模型丢失图片。图片原文件只随本次请求发送，不会作为后续聊天的视觉记忆保存；GIF 动态内容的理解能力由模型决定。

QQ 官方平台在部分消息中不会提供 At 组件，只会把机器人显示名放在文本开头。可在设置中的“文本 @ 名称”填写平台实际显示名（每行一个），插件只匹配消息开头的完整 `@名称`；填写后该列表作为唯一文本名称来源，留空时才回退到当前人格名称。AstrBot 通常只能稳定提供机器人 ID，不能跨平台可靠提供显示昵称，因此建议填写平台昵称。

### 主动发言

群聊冷场超过阈值后，由 AI 结合人格和最近话题决定是否主动开口。默认关闭。

| 配置 | 默认 | 说明 |
|---|---|---|
| 静默阈值 | 20 分钟 | 群聊多久没消息后考虑发言 |
| 主动冷却 | 60 分钟 | 两次主动发言的最小间隔 |
| 最低心流 | 45 | 低于此值不主动开口 |
| 每日上限 | 3 次/群 | 防止话痨 |

生成话题期间群里若恢复活跃，会自动取消发言。

### 话题偏好

可手动配置希望机器人关注的话题或短语，也可以让 AI 根据人格生成偏好。偏好只作为当前上下文的辅助信号，帮助 AI 判断是否适合参与讨论；`use_ai_keywords` 开关控制 AI 生成的偏好是否启用。Dashboard 提供匹配预览。

### 一键配置

三套联动参数预设，一键套用：

| 预设 | 适用场景 |
|---|---|
| 日常闲聊群 | 50~200 人的日常群（默认） |
| 热闹大群 | 200 人以上的活跃群 |
| 安静小群 | 潜水群、小群 |

预设只改数值参数，不碰开关、名单、提示词、模型选择。应用后仍是普通配置，可以继续手动微调。

## 指令

| 指令 | 说明 |
|---|---|
| `/mindflow` | 查看当前群状态：心流值、上次发言、缓冲 |
| `/mindflowreset` | 重置当前群状态 |
| `/keywords` | 查看当前生效的话题偏好 |
| `/genkeywords` | 让 AI 按人格生成话题偏好 |

## Dashboard

插件自带一个 Dashboard 页面，三个面板：

- 插件设置：一键配置 + 全部参数可视化编辑（开关、滑块、下拉、提示词、判断模型、超时）
- 话题偏好：手动增删、AI 生成（可选参考人格，兼容 v2/v3 人格系统）、匹配预览
- 状态面板：各群心流、发言统计、最近消息、最近决策、缓冲数，10 秒自动刷新

## 常见问题

**在群里 @ 别人，机器人会回复吗？**

不会误回。插件会识别 @ 的对象：点名机器人时必定回复；@ 别人时按正常流程判断，提示词里会写明「@了其他成员」，AI 只在内容明显需要它参与时才发言。

**调试日志看不到插件的输出？**

插件日志级别独立于 AstrBot 全局日志。排查问题时打开插件设置里的"调试模式"，插件会以 INFO 级别输出 @ 检测详情和消息描述。

**主动发言为什么一直不触发？**

先确认已开启"启用主动发言"。触发条件：群冷场超过静默阈值、心流达到最低值、当天发言次数未达上限。心流不足时（群长期不活跃）不会主动开口，这是有意设计的。

**换了人格没生效？**

插件 30 秒缓存人格设定，最多等半分钟；也可以重载插件立即生效。

## 代码结构

```
astrbot_plugin_humanlike/
├── main.py              # 插件入口：事件处理、指令、流程调度、预设、Web API
├── metadata.yaml        # 插件元数据
├── _conf_schema.json    # 配置项定义
├── engine/              # 纯逻辑层
│   ├── state.py         # 群状态数据结构
│   ├── flow.py          # 心流计算、@/名字检测
│   ├── debounce.py      # 防抖判断
│   └── accumulator.py   # 消息累积、随机抖动计时器
├── ai/                  # AI 交互层
│   ├── persona.py       # 人格读取（强制继承 + 缓存）
│   └── client.py        # LLM 调用封装
└── pages/
    └── dashboard/       # Dashboard 页面
```
