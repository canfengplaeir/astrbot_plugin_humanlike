# 拟人化群聊助手 (astrbot_plugin_humanlike)

让 AstrBot 在群聊中像真人一样说话——不再每条消息都回复，而是基于心流引擎、消息累积和 AI 判断，自主决定何时参与对话。

本插件定位为 **AstrBot 自主回复能力的增强层**：人格、名字、语气完全继承 AstrBot 当前选中的默认人格，插件只负责"何时说、说多少、要不要主动说"。

## 核心问题

默认 AstrBot 对群聊**每条消息**都回复，像话痨。本插件解决三个问题：

| 问题 | 方案 |
|------|------|
| 每条消息都回复 | 心流引擎 + 累积模式 → 有选择地参与 |
| 短时间刷屏 | 防抖 → 动态冷却 + 频率限制 + 随机沉默 |
| 回复缺乏人格 | 强制继承 AstrBot 人格系统 → 猫娘/傲娇等人设完整保留 |

## 功能总览

| 模块 | 功能 |
|------|------|
| **心流引擎** | 每群独立 0-100 参与意愿：@/人格名+35、关键词+18、问句+20、群活跃+10；自然衰减（0.03/秒）、发言后-18、同人连发惩罚 |
| **消息累积** | 普通消息缓冲，沉默 15±30% 秒后批量处理；@/被叫名字/心流≥70 立即触发；缓冲 15 条强制处理 |
| **防抖** | 动态冷却（心流高→4s、低→10s）、频率限制（12 次/60 秒）、心流阈值 35、10% 随机沉默、20s 退避重试 |
| **AI 判断+回复** | 两级 LLM：先判发言/沉默再生成回复；支持判断专用便宜模型；人格强制继承（30s 缓存）；全部调用带超时（判断 12s / 回复 45s / 关键词 30s / 主动 25s） |
| **@必定回复** | 被点名（含纯 @ 无文字）跳过 AI 判断与防抖直接回复；@全体不算点名 |
| **主动发言** | 群冷场 ≥20 分钟 → AI 按人格和最近话题决定是否开口；60 分钟冷却、每日 3 次上限、心流门槛 45；生成期间群恢复活跃自动取消 |
| **关键词系统** | 手动关键词 + AI 按人格自动生成；`use_ai_keywords` 开关控制 AI 词参与匹配；Dashboard 测试器 |
| **一键配置** | 三套联动参数预设（日常闲聊群 / 热闹大群 / 安静小群），应用后仍可手动微调 |

> 默认数值基于「日常闲聊群」预设，均可在 Dashboard 调整或切换预设。

## 子系统

### 1. 心流引擎 (Flow Engine)

模拟人类注意力波动，每个群独立维护 0-100 的心流值。以下为「日常闲聊群」默认值，均可调。

**上升机制：**

| 触发条件 | 加成 | 说明 |
|----------|------|------|
| 被 @提及 | +35 | 直接叫到机器人 |
| 人格名被提到 | +35 | 人格名出现在消息中 |
| 匹配关键词 | +18 | 配置的兴趣话题 |
| 消息含问号 | +20 | 可能有人在提问 |
| 群聊活跃 | +10 | 60秒内多条消息 |
| 回复互动 | +15 | 机器人发言后 30s 内被叫人格名 |

**下降机制：**

| 触发条件 | 衰减量 |
|----------|--------|
| 自然流失 | 每秒 -0.03 |
| 发言后衰减 | -18 |
| 同一人连续发言 | -3/条（第 3 条起） |

### 2. 消息累积 (Accumulation)

模拟人看手机的习惯——消息轰炸时先不回复，安静下来再一起看。计时器带 ±30% 随机抖动，避免机械感。

**两条路径：**

| 路径 | 触发条件 | 行为 |
|------|----------|------|
| 立即处理 | 被@、被叫人格名、心流≥70 | 跳过等待，直接判断回复 |
| 累积等待 | 普通聊天消息 | 加入缓冲队列，15±30% 无新消息后批量处理 |

### 3. 消息防抖 (Debounce)

三层保护避免刷屏：

- **动态冷却**：心流 100→4s，心流 50→7s，心流 0→10s（下限/上限可调）
- **频率限制**：默认每 60 秒最多 12 次（窗口与次数均可调）
- **随机沉默**：默认 10% 概率
- **防抖重试**：拦截后 20s 退避重试，超 3 次跳过防抖直接交 AI 判断
- 被直接点名（@）时豁免全部防抖检查，必定回复

### 4. AI 判断与回复

两级 LLM 调用。**人格强制继承** AstrBot 当前选中的默认人格，插件不提供替代。支持为判断和回复分别配置不同模型（降低成本）。所有 LLM 调用均带超时（判断 12s / 回复 45s / 关键词 30s / 主动 25s，可调），超时/失败自动回退启发式规则，不会挂起流程。

### 5. 主动发言 (Proactive)

群聊冷场后，机器人像真人一样主动开口（默认关闭）：

| 配置 | 默认 | 说明 |
|------|------|------|
| 启用主动发言 | 关 | 开启后周期性检查各群 |
| 静默阈值 | 20 分钟 | 群聊连续无消息多久后考虑发言 |
| 主动冷却 | 60 分钟 | 两次主动发言最小间隔 |
| 最低心流 | 45 | 高于被动回复阈值（35），兴致一般时不硬聊 |
| 每日上限 | 3 次/群 | 防止话痨 |

触发后由 LLM 结合人格与最近聊天内容决定：要么保持沉默，要么输出 1-2 句起话题的话。主动发言同样计入防抖窗口与心流衰减；生成话题期间群聊恢复活跃会自动取消。

### 6. 一键配置预设 (Presets)

Dashboard「插件设置 → 一键配置」提供三套**联动调整**的参数方案：

| 预设 | 适用场景 | 特点 |
|------|----------|------|
| **日常闲聊群** | 50~200 人（默认） | 热闹跟得上、冷静等一等、冷场偶尔撩 |
| **热闹大群** | 200+ 人活跃群 | 节奏快、参与度高、话多一些 |
| **安静小群** | 潜水群/小群 | 低存在感、克制发言、极少主动打扰 |

预设应用只覆盖数值参数（开关/名单/提示词/模型选择不触碰），应用后仍是普通配置，可手动微调任意参数。

## WebUI 页面

插件提供统一的 **Dashboard** 页面，左侧边栏切换三个功能面板：

| 面板 | 功能 |
|------|------|
| **插件设置** | 一键配置预设（三套方案）+ 全部配置项可视化操作：开关/滑块/数字输入/下拉/提示词编辑/AI判断专用模型选择/超时，一键保存即时生效 |
| **关键词管理** | 手动添加删除 + AI 生成（可选参考人格，兼容 v2/v3 人格系统）+ 实时关键词测试器 |
| **状态面板** | 所有群心流进度条、发言统计、最近消息、缓冲数、主动发言状态，10s 自动刷新 |

## 设计原则

1. **人格强制继承**：人格/名字/语气一律取自 AstrBot PersonaManager，插件只决定"何时说、说多少"
2. **累积优先**：消息爆发时缓冲，安静后批量处理，模拟人类读消息行为
3. **防抖优先于 AI**：防抖检查在 LLM 调用之前，避免不必要的 API 开销
4. **错误容忍**：AI 调用失败/超时自动回退启发式规则，绝不挂起流程
5. **群间隔离**：心流、上下文、计时器、缓冲全部按群独立
6. **拟人细节**：计时器随机抖动、同人打断惩罚、回复互动奖励、冷场才主动开口
7. **参数联动**：三套预设保证心流衰减、主动门槛、防抖窗口等参数数学自洽（聊嗨后冷场仍有余兴主动开口）
